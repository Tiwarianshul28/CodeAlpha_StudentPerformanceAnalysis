
# Student Performance Analysis

## Project Overview
This project analyzes student marks in Maths, Science, and English using Python. It calculates total marks and average marks, identifies the top-performing student, and creates a bar chart for subject-wise performance.

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV

## Features
- Displays student marks in a table
- Calculates total and average marks
- Identifies the top-performing student
- Generates a subject-wise bar chart
- Exports results to a CSV file

## Project Files
- `student_analysis.py` - Main Python source code
- `student_performance_results.csv` - Student results
- `student_performance_chart.png` - Performance visualization

## How to Run
1. Install Python.
2. Install required libraries:
   `pip install pandas matplotlib`
3. Run the program:
   `python student_analysis.py`

## Sample Result
The program identifies Karan as the top-performing student, with an average of 92.33 marks.
